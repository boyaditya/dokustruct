about this project

    
DokuStruct runs document extraction in your browser

    
DokuStruct is a browser native port of RapidDoc, which comes from MinerU. It does OCR, layout, tables, formulas and reading order with ONNX Runtime Web. No server. Your files never leave the browser. This is my Computer Science thesis.


    
What it does

    
    
      
  • text and layout with PP-OCRv5 and PP-DocLayout, keeps reading order
    • 
      
  • tables with SLANet-Plus and UNet
    • 
      
  • formulas as LaTeX with PP-FormulaNet Plus, shown with KaTeX
    • 
      
  • orientation fix, batch of files, export to Markdown and JSON, works offline after first load
    • 
    


    
How it works

    
PDF or image is sliced into pages. Each page goes through layout detection, text recognition, then table and formula recognition, then reading order. Results are assembled into Markdown and JSON with boxes you can inspect on the page.

    
Everything runs locally. The app picks WebGPU when available and falls back to WASM. Large files are split into small windows so the browser stays responsive and does not run out of memory.


    
Tested

    
Checked on OmniDocBench v1.6 with 350 pages for output and 50 for timing, seed 42. Port fidelity to Python is about 0.95 F1. Proxy composite is about 71.7 for this build and 74.3 for Python. Full workbook and sample list are in docs/evidence.


    
References and detail

    
Built from MinerU 2.6.4 to RapidDoc 0.9.4 to DokuStruct 0.1.0. Stack is ONNX Runtime Web, OpenCV.js and PDF.js. My Computer Science thesis, 240 tests, Apache 2.0. See porting notes and benchmark method for full detail.
